# 🍽️ Cardápio Digital em C

## 📌 Sobre o projeto

O **Cardápio Digital** é um sistema desenvolvido em linguagem C que simula o funcionamento de um cardápio de restaurante por meio do terminal.

O projeto foi criado com o objetivo de praticar fundamentos de programação, estruturas condicionais, laços de repetição e manipulação de variáveis.

O sistema permite navegar pelas categorias do cardápio, selecionar pratos com diferentes preços, registrar pedidos e calcular o valor total da compra.

## 🚀 Funcionalidades

- 📋 Exibição de um cardápio organizado por categorias.
- 🍔 Seleção de diferentes pratos.
- 💰 Preços individuais para cada produto.
- 🛒 Registro dos itens selecionados pelo usuário.
- 🧮 Cálculo automático do valor total do pedido.
- 🔄 Navegação e retorno ao menu principal.
- ✅ Finalização do pedido com apresentação dos itens escolhidos.

## 🛠️ Tecnologias utilizadas

- **Linguagem C** — Desenvolvimento do sistema.
- **GCC** — Compilação do código.
- **VS Code** — Ambiente de desenvolvimento.

## 🧠 Conceitos praticados

Durante o desenvolvimento, foram utilizados conceitos fundamentais da programação:

- Variáveis e tipos de dados.
- Operadores aritméticos e relacionais.
- Estruturas condicionais (`if`, `else`).
- Estruturas de seleção (`switch`, `case`).
- Estruturas de repetição (`do-while`).
- Entrada e saída de dados (`scanf`, `printf`).
- Manipulação de strings.
- Organização da lógica e controle do fluxo do programa.

## 💻 Como executar

1. Faça o download ou clone este repositório.
2. Abra o projeto no VS Code ou em outro editor de sua preferência.
3. Utilize um compilador compatível com a linguagem C.
4. Compile o arquivo principal e execute o programa pelo terminal.
5. Navegue pelo cardápio e realize seus pedidos.
